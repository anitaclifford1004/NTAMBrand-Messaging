# Project Reference

## NTAM_Brand_Messaging_Proposal.pdf

Ogilvy's proposed scope of work for the Northern Trust Asset Management (NTAM)
brand & messaging engagement (August 2026). Not research findings — this is the
project proposal itself:

- **The challenge / the ask** — sharpen NTAM's positioning vs. competitors and
  connect it to the "One Northern Trust" enterprise narrative and the "If You
  Know, You Know" creative platform.
- **Phase I — Research, Analysis & Recommendation (8 weeks)**: competitive audit
  (10 competitors), leadership interviews, value proposition assessment
  (table stakes vs. differentiators, proof point strength), 3 positioning
  options tested against synthetic audiences (built from 3 supplied personas),
  whitespace/opportunity mapping, scoring against a shared assessment
  framework, final positioning recommendation.
- **Phase II — Messaging Architecture Framework (6 weeks)**: NTAM x Ogilvy
  workshop, messaging architecture framework (mission → principles →
  positioning → attributes → RTBs), enterprise brand alignment (Corporate /
  Asset Management / Wealth Management / Asset Servicing), activation &
  governance guide.
- Timeline (8/24–11/16), budget options (NewtonX $324,638 vs. GLG $354,938),
  and team.

Use this as background on project scope and deliverable shapes (e.g. the
messaging architecture framework diagram, positioning statement construct,
assessment scoring table) — not as source content for the synthesis deck
itself. Actual research/synthesis content will be supplied separately.
