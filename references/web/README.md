# Web Design References

Websites used as visual and structural references for NTAM brand messaging decks.

## bidnam/ — Bidnam "Work" page (bidnam.com/work.html)

Screenshots of a strategy consultancy's case-study index, supplied by the team
(the live site could not be fetched from this environment):

- `work-list-collapsed.png` — default state: every client collapsed to a name row
- `work-list-verizon-expanded.png` — Verizon Business row expanded
- `work-list-andmore-expanded.png` — Blackstone / Andmore row expanded

Used as a reference for a restrained, editorial look and an index-to-detail
structure (e.g. a case-study, competitor or positioning-option roll-up in the
NTAM deck). It informs tone and layout, not content.

### Structure

- **Page header**: short title ("Work") plus a one-line framing sentence in a
  muted colour ("Select clients and projects across industries, stages, and
  inflection points.").
- **Index list**: one full-width row per client (IBM, UiPath, Verizon Business,
  Blackstone / Andmore, Blackstone / Sustana, 7-Eleven, Fierce Finance) with a
  very large serif name and a hairline rule between rows. Parent / portfolio
  company pairs are written with a slash ("Blackstone / Andmore").
- **Accordion detail**: the selected row expands into a tinted panel, and the
  other rows fade to grey so it stands out. The panel holds four layers, in order:
  1. Client name (unchanged size)
  2. **Practice tags**: uppercase, letter-spaced, square-cornered chips
     (e.g. GO-TO-MARKET · BRAND STRATEGY · PRODUCT STRATEGY · CAMPAIGN STRATEGY)
  3. **One-sentence summary** in the serif (e.g. "Category reframe, brand
     positioning, architecture and naming, and ecosystem strategy for a
     PE-backed B2B wholesale marketplace.")
  4. **Deliverable pills**: sentence-case, fully rounded chips
     (e.g. Brand Positioning · Portfolio Strategy · Messaging Architecture · GTM Strategy)
- Each expanded case uses its own tint and a matching accent bar on the left
  edge (Verizon: warm blush and red; Andmore: cool grey and pale blue).

### Visual system (sampled from the screenshots)

| Role | Value |
|---|---|
| Page background | `#F8F6F1` (warm off-white) |
| Primary text / names | `#202020` |
| Intro / subhead text | `#4F5C4D` (muted grey-green) |
| De-emphasised rows | `#ACABA8` |
| Row dividers | `#E5E3DE` hairline |
| Accent A: panel / bar | `#F1DDD8` / `#BB2C24` |
| Accent A: chip fill | `#E5D3CD` |
| Accent B: panel / bar | `#EAEDEE` / `#B6C6E3` |
| Accent B: chip fill | `#DBDDDE` |

- **Type**: a high-contrast Garamond-style display serif (looks like Cormorant
  Garamond) for headings, names and body. Note the old-style figures in
  "7-Eleven" and "B2B". Tags and pills use a clean grotesque sans: uppercase and
  tracked for practice tags, sentence case for deliverables.
- **Scale**: names are very large (roughly 4–5× the intro line) and are the
  page's main graphic element. There is no imagery or iconography.
- **Density**: generous whitespace, left-aligned throughout, one idea per row.

### How it can carry into the NTAM deck

- **Index slides** (competitive set, positioning options, enterprise brands):
  a list of large serif names with hairline rules, with the item under
  discussion highlighted and the rest greyed out. This works as a section
  navigator across slides.
- **Detail slides**: reuse the four-layer anatomy (name → category tags →
  one-line summary → deliverable or attribute pills). It fits competitor
  profiles (tags = positioning territory, pills = proof points) and the three
  positioning options.
- **Colour per item**: give each competitor or option its own soft tint and
  accent bar, with the NTAM / Northern Trust palette in place of the accents
  sampled here.
- **Tone**: quiet, typographic and confident. It suits an asset-management
  audience and the understated "If You Know, You Know" platform.
