# Deck Design References

Reference decks used as structural and visual templates for NTAM brand messaging decks.

## Citizens_Example.pptx

"Citizens Consumer Ecosystem & Loyalty Synthesis" — a 21-slide research synthesis deck
(consumer ecosystem analysis, competitive/category review, loyalty framework, tiered
product recommendations). Used as a reference for slide structure, section framing, and
layout patterns (numbered section navigators, insight-led headlines, stat callouts,
before/after case comparisons) when building the analogous NTAM deck.
